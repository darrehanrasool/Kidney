1. PROJECT ARCHITECTURE & OVERVIEW
================================================================================

KidneyCare-AI is a modular, research-grade clinical machine learning platform
integrating structured electronic health records (EHR), B-mode renal ultrasound,
and CT imaging into a unified representation space (NephroFusionNet).

Directory Structure:
  configs/         - Hardware, model, training, and visualization configs
  data/raw/        - Raw clinical (UCI, NHANES) and imaging (Ultrasound, CT) cohorts
  data/splits/     - Leakage-safe train, validation, and holdout test splits
  src/kidneycare/  - Core library modules (data, models, training, evaluation, UI)
  scripts/         - Automated CLI pipelines for download, training, and evaluation
  tests/           - 22 unit and integration tests with 100% pass rate
  visualizations/  - 10 clinical publication figures (ROC, PR, Calibration, etc.)
  outputs/         - Trained model bundles and checkpoint archives

2. DATASETS & MULTIMODAL POOLS
================================================================================

1. UCI Chronic Kidney Disease (400 patients, 24 attributes):
   Gold-standard tabular baseline for CKD detection.
2. NHANES Kidney Cohort (5,000 patients):
   Large-scale epidemiological cohort with eGFR and UACR.
3. Synthetic CKD Benchmark (400 patients):
   Deterministic offline reproduction fixture with zero network dependency.
4. Renal B-Mode Ultrasound (600 images across 4 classes):
   Speckle-filtered ultrasound images (Normal, Cyst, Stone, Tumour).
5. Renal CT Scans (600 images across 4 classes):
   Hounsfield-windowed axial slices (Normal, Cyst, Stone, Tumour).
6. Paired Multimodal Cohort (1,000 cases):
   Harmonized clinical lab panel + ultrasound + CT paired observations.

3. MATHEMATICAL FOUNDATIONS & CLINICAL FORMULATIONS
================================================================================

- 2021 Race-Free CKD-EPI eGFR:
    eGFR = 142 * min(Scr/kappa, 1)^alpha * max(Scr/kappa, 1)^(-1.200)
               * 0.9938^Age * [1.012 if female]
    (Females: kappa=0.7, alpha=-0.241; Males: kappa=0.9, alpha=-0.302)

- Perona-Malik Anisotropic Diffusion (Speckle Filtering):
    dI/dt = div(c(||grad I||) grad I)
    c(||grad I||) = 1 / (1 + (||grad I|| / kappa)^2)

- Feature Tokenizer with Learned Missingness (FT-Transformer):
    t_j = (1 - m_j)*(x_j*w_j + b_j) + m_j*u_j + e_j
    (m_j is missingness flag; u_j is learned missing-token vector)

- Consistent Rank Logits (CORAL) Ordinal Staging:
    Loss = -sum_{k=1}^{K-1} [ y^(k)*log sigma(g(x) + b_k) + (1 - y^(k))*log(1 - sigma(g(x) + b_k)) ]
    (Guarantees ordered monotonic thresholds for KDIGO stages G1-G5)

- Multi-Task Homoscedastic Uncertainty Weighting:
    Loss = sum_{i=1}^T [ (1 / (2*sigma_i^2))*Loss_i + log(sigma_i) ]

- Inductive Conformal Prediction & Clinical Abstention:
    Prediction Set C(x) = { y in Y : P(y|x) >= 1 - q_hat }
    Coverage Guarantee: 1 - alpha = 95%
    Safety Rule: If |C(x)| > 2 or P(CKD) in [0.45, 0.55], abstain and flag:
    "REFER TO NEPHROLOGY SPECIALIST"

6. How to Run the Project
================================================================================

Step 1: Run Full Test Suite (22 Tests Passing)
```bash
PYTHONPATH=src pytest tests/ -v
```

Step 2: Prepare Clinical Splits
```bash
python3 scripts/prepare_data.py
python3 scripts/create_splits.py
```

Step 3: Train All Classical Models
```bash
python3 scripts/train_all.py
```

Step 4: Train Imaging & Multimodal Networks
```bash
# Trains RenalCNN with Anisotropic diffusion on Apple Silicon MPS
python3 scripts/train_imaging.py --epochs 15 --device mps

# Trains NephroFusionNet with Perceiver cross-attention and multi-task loss
python3 scripts/train_multimodal.py --epochs 20 --device mps
```

Step 5: Evaluate Models & Generate Reports
```bash
python3 scripts/evaluate_all.py
python3 scripts/generate_visualizations.py
```

Step 6: Launch Interactive Clinical UI Dashboard
```bash
python3 scripts/run_app.py --port 8080
```

Open http://localhost:8080 in your browser to interact with:
- Patient Biomarker inputs (Age, Serum Creatinine, Blood Urea, Albumin, BP, Glucose).
- Live 2021 Race-Free CKD-EPI eGFR calculation & KDIGO Stage assignment.
- Conformal Prediction Set (95% coverage) with automated Specialist Abstention alerts.
- Grad-CAM heatmap visualization for ultrasound and CT scans.
- Research literature benchmark matrix comparing Ma et al., Hannan & Pal, and Poonia et al.
