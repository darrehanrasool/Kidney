# Dataset Links & Data Availability

## Data Availability Statement

The dataset used in this study is publicly available and can be accessed from:

- **Kaggle**: [https://www.kaggle.com/datasets/mansoordaku/ckdisease](https://www.kaggle.com/datasets/mansoordaku/ckdisease)
- **University of California Irvine (UCI) Machine Learning Repository**: [https://archive.ics.uci.edu/ml/datasets/Chronic_Kidney_Disease](https://archive.ics.uci.edu/ml/datasets/Chronic_Kidney_Disease)  
  *(UCI Dataset ID 336: [https://archive.ics.uci.edu/dataset/336/chronic+kidney+disease](https://archive.ics.uci.edu/dataset/336/chronic+kidney+disease))*

> *No new data were created or collected specifically for this study.*
